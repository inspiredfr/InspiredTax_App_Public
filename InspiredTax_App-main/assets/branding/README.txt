InspiredTax — Complete Icon & Lockup Package
=====================================================
Updated 17 Jul 2026: filtered (diffuse + combined lighting) lockups and
light-mode marketing master integrated; iOS Light icon rebuilt to match;
stale stacked lockups retired; DM Sans font switch documented.
Full brand rationale now lives in /brand/BRAND_PALETTE_LOGO_DIRECTION.md —
this file stays purely a "what file goes where" map.

Icon: R monogram (Rand symbol + integrated +/= accent).
Dark palette: navy #010D30 bg / cyan #1ADDE3 R / mid-blue #0B52DA accent.
Light palette: off-white #F8F9FC bg / navy #010D30 R / mid-blue #0B52DA accent.
Wordmark: DM Sans SemiBold (600) — see /brand doc for verification caveat.

/mark/
  InspiredTax_mark_{mode}_foreground.png
                             ADDED 2026-09-14. The R glyph on a TRANSPARENT
                             background, 256x256, one per theme. This pair is
                             what every in-app mount of the mark uses (login,
                             onboarding, drawer, header, About) — it is the
                             only artwork here with no background swatch.
                             GENERATED, not hand-made: run
                             `node tools/make-mark-foreground.js` to rebuild,
                             `--check` to verify. Do not edit by hand.
                             Sources are the two /marketing/ masters, keyed
                             against their flat brand background (#010D30 /
                             #F8F9FC) and un-composited at the rim. As with
                             the transparent lockups below, this is a MATTE
                             rather than a lossless extraction — there is no
                             native transparent source. Edges were verified
                             against both themes, but do a visual pass before
                             relying on it over a busy background.
                             NOT for the launcher icon, the Play Store tile or
                             the favicons: those want a background, and keep
                             using the files above.

  InspiredTax_mark_{mode}_cropped.png
                             ADDED (QA 2026-08 design handoff, §5). Same R
                             glyph as the icon/lockup marks but tightly
                             cropped to the glyph itself (background swatch
                             trimmed) — the old inline app embeds had ~40%
                             padding around the R, which reads small at the
                             76x76 render size used in-app (login screen,
                               onboarding, About modal). Source for the
                             `.tlogo-dark`/`.tlogo-light` base64 embeds in
                             src/body.html.

  horizontal lockups would mean two visibly different logo treatments in

  style — flag if you need it before submission.
